# Completed tasks

**One file per completed task**, named for its number:
`task-completed-0007.md` holds T7 and nothing else.

Each file carries what the task was and the commit that finished it. A task
leaves [../../TASKS.md](../../TASKS.md) when it is done, so anything still in
that file is open by definition.

Milestones are groupings rather than entries: a milestone is finished when every
task under it has moved here. Nothing is numbered by milestone.

Tasks are a register like problems and questions — dense, append-only, never
renumbered — because an answered question's `## Outcome` may cite `T<n>`, and a
citation is only worth writing if something checks it resolves.
